# Minecraft Tower Defense 遊び方

Paperサーバー上の通常のサバイバルワールドで、チームのコアを守りながら襲撃を攻略する
タワーディフェンスです。バニラクライアントで遊べ、必須リソースパックはありません。

対象ビルドは Paper 26.2 build 87 / Java 25 です。

## まずやること

1. コア設置アイテムをクラフトします。
2. Overworldの通常の固体ブロックを右クリックして、コアを設置します。
3. コアを空手で右クリックして「防衛コア管理」を開きます。
4. 必要ならチームを作成・管理し、襲撃の印をクラフトします。
5. コアGUIからステージを選び、防衛戦を開始します。
6. 準備時間にタワーを設置し、ウェーブ中にコアとタワーを守ります。
7. 勝利報酬の研究結晶をコアGUIへ納品し、タワー研究や強化に使います。

## コアを作る・設置する

### レシピ

3×3の配置です。

```text
  I
I D I
  I
```

- `I`: 鉄インゴット ×4
- `D`: ダイヤモンドブロック ×1
- 結果: plugin所有の「コア」アイテム ×1

新しいコアアイテムの見た目は `RESIN_BRICKS`（樹脂レンガ）です。普通の樹脂レンガや
普通のネザースターはコアとして扱われません。

### 設置条件

コアアイテムをメインハンドに持ち、同じOverworldにある通常の固体ブロックを右クリック
します。設置先には次の制約があります。

- コア設置者がチームオーナーであること。
- タイルエンティティ付きのブロック、既存コア、危険な保護対象を選ばないこと。
- コア同士の距離、戦闘範囲、WorldBorder、設定済みの保護領域を満たすこと。
- 防衛戦の実行中ではないこと。

設置後の物理ブロックは `DRIED_KELP_BLOCK`（乾燥した昆布ブロック）です。コアの正体は
ブロック素材だけでなく、サーバーの登録情報で管理されます。

コアを右クリックするとGUIが開きます。GUIではチーム、資源庫、研究結晶の納品、タワー
研究、修繕、ステージ開始、コア移設を操作できます。コア移設は防衛戦外かつコアHP満タン
のときだけ使えます。

## チームで遊ぶ

最初のコア設置時、所属チームがなければ設置者のソロチームが自動作成されます。チームの
最大人数は8人です。コアGUIの「チーム」から管理画面を開けます。

### コマンド

```text
/td team invite <プレイヤー名>
/td team invites
/td team accept <招待コード>
/td team decline <招待コード>
/td team rename <チーム名>
/td team chat <メッセージ>
```

招待はコアGUIから近くのオンラインプレイヤー1人へ送ることもできます。GUI招待は6ブロック
以内に対象者が1人だけいるときに使用できます。オフラインの相手にはコマンド招待を使います。
チーム名の変更とメンバー招待はオーナーのみ、チームチャットはチームメンバーだけに届きます。
防衛戦中はチーム構成を変更できません。

## 襲撃の印を作って防衛戦を始める

### 襲撃の印のレシピ

すべて同じ形で、`P`は紙4個、`S`はステージ素材1個です。

```text
  P
P S P
  P
```

結果はplugin所有の `ECHO_SHARD`（「襲撃の印」）です。襲撃の印は1個ずつクラフトされ、
スタックできません。

| ステージ | `S` に使う素材 | ウェーブ数 |
|---:|---|---:|
| 1 | 金インゴット | 5 |
| 2 | ダイヤモンド | 8 |
| 3 | エメラルド | 10 |
| 4 | アメジストの欠片 | 12 |
| 5 | プリズマリンクリスタル | 15 |
| 6 | クォーツ | 18 |
| 7 | グロウストーンダスト | 21 |
| 8 | レッドストーン | 24 |
| 9 | ラピスラズリ | 27 |
| 10 | ネザライトの欠片 | 30 |

ステージ1は初期状態で解放されています。ステージを勝利すると次のステージが解放されます。
ステージ2以降は対応する襲撃の印が必要です。ステージ10より上は技術的には検証可能ですが、
現在の通常クラフトレシピはステージ1〜10です。

### 開始方法

次のいずれかで開始できます。

- コアを空手で右クリックしてGUIを開き、「所持中の最高ステージを開始」を押す。
- コアGUIのステージボタンから開始したいステージを選ぶ。
- 対応する襲撃の印をメインハンドに持ち、登録済みコアを右クリックする。

開始するプレイヤーはチームメンバーで、コアの戦闘範囲内にいる必要があります。襲撃の印は
開始処理の一部として1個だけ予約・消費されます。失敗や復旧が起きても、同じ印が二重に
消費されないようサーバー側で管理されます。

## タワーを作って置く

タワーアイテムをクラフトし、メインハンドに持って通常の固体ブロックを右クリックします。
クリックしたブロックの上の空気ブロックにArmorStand型のタワーが設置されます。

設置には次の条件があります。

- 設置者がチームメンバーであること。
- チームのコア周辺の戦闘範囲内であること。
- クリック元が通常の固体ブロックで、設置先が空気であること。
- コア、タイルエンティティ、既存タワー、WorldBorder外を選ばないこと。
- カウントダウン中またはウェーブ中ではないこと。準備時間とインターミッションに設置できます。
- チームのタワー上限を超えないこと。上限は `8 + 2 × 最高クリアレベル`、最大40基です。

### タワーのレシピ

各行は3×3配置です。

| タワー | 配置 | 材料 |
|---|---|---|
| アロー | `IRI / RDR / IRI` | `I` 鉄、`R` レッドストーン、`D` ダイヤモンド |
| キャノン | `CGC / GIG / CGC` | `C` 丸石、`G` 火薬、`I` 鉄 |
| フロスト | `PIP / IDI / PIP` | `P` 氷塊、`I` 鉄、`D` ダイヤモンド |
| ライトニング | `RER / ECE / RER` | `R` レッドストーン、`E` エンダーパール、`C` 銅インゴット |
| サポート | `GAG / AEA / GAG` | `G` 金インゴット、`A` アメジストの欠片、`E` エメラルド |
| スナイパー | `FIF / IEI / FIF` | `F` 羽根、`I` 鉄、`E` エンダーアイ |
| フレイム | `BBB / BFB / BDB` | `B` ブレイズパウダー、`F` ファイヤーチャージ、`D` ダイヤモンド |

`/` は行の区切りです。すべてplugin所有のUUID付きアイテムになり、同じ材料の普通の
アイテムを置き換えるだけではタワーになりません。

### タワーを使う

タワー本体を右クリックすると「タワー管理」が開きます。ここで対象優先を選び、研究で
解放された個体レベルまで強化し、必要なら修理や戦闘ブーストを行います。対象優先には
次があります。

- コアに近い
- 距離が近い
- HPが高い
- HPが低い
- ボス優先

タワーの役割は次のとおりです。

| 種類 | 役割 |
|---|---|
| アロー | 標準的な単体攻撃 |
| キャノン | 選んだ敵を中心にした範囲攻撃 |
| フロスト | ダメージとSlowness |
| ライトニング | 近くの敵へ連鎖攻撃 |
| サポート | 味方タワーの射程・威力・速度を強化 |
| スナイパー | 長射程の単体攻撃 |
| フレイム | 範囲ダメージと炎上 |

攻撃が成立したときだけ、タワーごとに異なるvanillaパーティクルが表示されます。パーティクル
は追加ダメージやブロック破壊を起こさず、リソースパックも必要ありません。

防衛戦が始まった後は、タワーの回収・移設はできません。タワーが敵に破壊された場合、
そのタワーアイテムは自動返却されません。

## コアGUIで研究と資源を使う

### 研究結晶を納品する

防衛戦の勝利報酬として受け取ったplugin所有の「研究結晶」を、コアGUIの「研究結晶を納品」
から研究ポイントへ変換します。メインハンドに持つ必要はありません。プレイヤー自身の
メインインベントリ全体とオフハンドが対象です。

次の場所は対象外です。

- 開いているチェストなど外部インベントリ
- クラフト枠
- カーソル上
- 防具スロット

他チームの結晶、普通のアメジストの欠片、PDCが壊れたアイテム、使用済みの結晶は消費
されません。納品後はコアGUIの「タワー研究」からタワー種別ごとの研究レベルを購入します。
研究ポイントと研究レベルはチーム共有です。

### 資源庫・修理・ブースト

コアGUIの「コア資源庫」ではチーム資源と、防衛戦中に仮確保された資源を確認できます。
コアやタワーの修理、個体レベル強化、戦闘ブーストにはそれぞれ利用可能な資源が必要です。
戦闘ブーストとタワー修理は準備時間またはインターミッションに行ってください。

## 防衛戦の進め方

防衛戦はおおむね次の順に進みます。

```text
カウントダウン → 準備時間 → ウェーブ → インターミッション
                         ↘ 最終ウェーブ後は勝利／失敗・復旧
```

- 参加者は開始時のチームメンバーと、戦闘範囲内にいるプレイヤーとして固定されます。
- 敵はウェーブごとに出現し、コアへ到達するとコアHPを攻撃します。
- コアHPが実際に減ったときだけ、戦闘範囲内のプレイヤーへ警告音が鳴ります。
- 破壊兵は近くのタワーを攻撃することがあります。タワーHPは管理GUIで確認できます。
- 現在の設定では敵による地形変更（ブロック破壊・設置）は無効です。
- 全ウェーブを倒すと勝利し、チームのクリアレベルと報酬が更新されます。
- コア破壊、参加者不在、管理者による中止では勝利報酬は発行されません。

## 管理者用テストコマンド

サーバー管理者（`towerdefense.admin`、通常はOP）には、実機確認用のコマンドがあります。
通常プレイヤーの進行にはコアGUIを使ってください。

```text
/td admin core
/td admin simulate [stage]
/td admin status
/td admin abort
```

- `/td admin core`: 見ている6ブロック以内の固体ブロックをテスト用コアとして登録します。
- `/td admin simulate [stage]`: 襲撃の印を使わず、指定ステージをシミュレーションします。省略時はステージ1です。
- `/td admin status`: 現在のフェーズ、ウェーブ、敵数、コアHP、処理メトリクスを表示します。
- `/td admin abort`: 実行中の防衛戦を安全に中止・復旧します。

## 困ったとき

### コアアイテムを置けない

クラフトしたplugin所有のコアをメインハンドに持っているか確認してください。普通の樹脂
レンガ・普通のネザースターは使えません。また、コア設置者はチームオーナーである必要が
あり、設置先は通常のOverworld固体ブロックでなければなりません。

### コアGUIが開かない

メインハンドを空にして、登録済みの乾燥した昆布ブロックを右クリックしてください。チーム
メンバー以外はコアGUIを開けません。

### ステージを開始できない

選択したステージが解放済みか、対応する襲撃の印を持っているか、コアの戦闘範囲内にいるかを
確認してください。襲撃の印を使う場合は、登録済みコアをメインハンドで右クリックする方法も
使えます。

### タワーを置けない

タワーアイテムは1個ずつクラフトされます。チーム参加、コア周辺、固体ブロックの上の空気、
防衛フェーズ（準備時間またはインターミッション）を確認してください。チーム上限に達して
いる場合や、研究レベルが個体レベルに足りない場合も設置できません。

### 研究ポイントが増えない

報酬で得た同じチームの研究結晶を使っているか確認してください。普通のアメジストの欠片や
別チームの結晶は対象外です。納品操作は防衛戦外に、コアGUIから行います。

## 旧アイテムとの互換性

- 旧形式でplugin PDCが付いた `NETHER_STAR` コアは継続して使用できます。
- 旧形式でplugin PDCが付いた `ENDER_EYE` 襲撃の印は読み込め、ログイン時に新しい
  `ECHO_SHARD` 表示へ移行されます。
- PDCのない普通の素材は、見た目が似ていてもpluginアイテムとして扱われません。
